# 人工补拍说明

以下素材为运营可选项，不应因缺失被表述为当前后台必填。

1. 在开发者工具或真机进入英雄编队，截取包含已解锁英雄与“确认”按钮的稳定画面，保存为 `03_collection.jpg`。
2. 进入英雄介绍或背包，截取完整内容画面，保存为 `04_challenge.jpg` 或 `05_progression.jpg`；不要使用空白页、调试层、系统状态栏或鼠标指针。
3. 击败 Boss 后，截取 Boss 宝箱交互或英雄候选画面，保存为 `06_result_or_second_mode.jpg`。
4. 每张仅截游戏画布，稳定等待至少 1 秒；竖屏导出 1080×1920 JPG、sRGB、单张不超过 5 MB。不得拼贴、添加文字或用重复画面凑数。
5. 需要审核辅助截图时，仅记录入口；不要触发真实广告、支付、外链或分享。
