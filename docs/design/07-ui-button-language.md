# UI 按钮视觉语言

**版本：** 0.1.0

## 目标

为所有可点击操作建立统一的高能漫画式反馈：硬边、斜切、强对比与明确的按下位移。视觉参考是现代都市怪盗漫画的张力，不复用任何特定作品的图形、字体或标志。

## 结构与动态

- 按钮使用左上与右下斜切角、粗黑描边、右下错位黑色投影。
- 顶部保留一条高光，并以斜向色块制造速度感。
- 点按时内容整体向下移动 4px，投影不动；现有页面的缩放/闪亮动画继续叠加。
- 禁用按钮统一为深灰、低对比文字，避免被误认为可操作。

## 颜色语义

| 颜色 | 用途 |
|---|---|
| 红 / 洋红 | 开始远征、下一关、结算等主行动 |
| 青 | 分享、授权等外部或信息操作 |
| 黄 | 金币、收益、放弃招募等经济操作 |
| 紫 | 导航、排行、翻页与次级操作 |
| 绿 | 确认、背包等安全完成操作 |
| 深灰 | 返回、跳过、取消与禁用状态 |

## 战斗状态条

- 怪物与玩家 HP 条沿用同一斜切外框、粗黑描边和右下投影，避免战斗 UI 出现不同来源的组件。
- 敌方 HP 使用洋红到亮粉的填充；玩家 HP 使用金黄到亮黄的填充，并保留青色警示光。
- Boss 条持续呼吸外发光，低于 25% HP 时以更快的描边脉冲警告；敌人受击时边框爆闪白色。
