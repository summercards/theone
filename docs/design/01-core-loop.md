# 核心玩法与单局循环

**版本：** 0.2.0  
**实现来源：** `js/page_game.js`、`js/page_hero_select.js`、`js/data/monster_state.js`

## 玩家目标

玩家从酒馆选择至少一名、最多五名英雄进入一次连续战斗。在 6×6（部分技能可扩大）的消除棋盘上完成有效交换，累积攻击槽并连续击败怪物；每次胜利后立即出现下一关怪物，直到玩家失败才结算本局。

## 主线流程

```text
首页 → 酒馆选队 → 开始连续战斗
→ 消除 / 连锁 / 技能 → 攻击槽结算 → 怪物受伤或反击
→ 击杀怪物并立即加载下一关 → 直到失败 → 本局结算
```

### 进入关卡

- 酒馆确认时要求队伍至少有一名英雄。
- 关卡编号读取本地存档 `lastLevel`；缺省时从第 1 关开始。
- 玩家总生命值为所有当前出战英雄 HP 之和。
- 默认棋盘为 6×6，允许方块为 A–F。关卡配置可以覆盖这两个参数。

### 玩家操作

- 玩家交换相邻两个格子；没有形成消除时交换会撤销。
- 有效交换触发消除、掉落、补块与自动连锁。
- 每次有效交换使 `gaugeCount` +1。达到 5 次后，会延迟结算当前攻击槽并清空全队技能充能。
- 连锁的颜色种类会累积连击计数；稳定后，以“攻击槽当前值的 10% × 连击数”加到攻击槽。

### 攻击与敌方回合

- 攻击槽结算时会播放投射物并对怪物造成该槽内全部伤害，然后清空攻击槽。
- 怪物未死亡时，主线模式在攻击结算后进行一次反击；怪物伤害可为固定值或 `[最小值, 最大值]` 随机值。
- 玩家总生命降到 0 时进入失败状态；怪物 HP 降到 0 时进入胜利结算。

## 单关胜利与连续推进

- 获得本关怪物配置的金币；金币先进入本局计数。
- 出战英雄获得经验：`关卡等级 × 5 + 10 + Boss 额外 50`。
- 主线在第 2、4、6、8、10 关可自动解锁指定英雄；有空队伍槽位时自动加入。
- 保存最高关卡、单次最高伤害和本局最高金币等排行榜统计。
- 不显示中间胜利/奖励/选人弹窗。
- 短暂显示关卡推进反馈后，自动加载 `currentLevel + 1` 并重新生成棋盘。
- 玩家当前 HP、队伍和技能充能保留到下一只怪物；攻击槽、有效交换计数与棋盘会重置。

## 失败与退出

- 失败画面是本局唯一的结算画面；它应显示本局达到的关卡和获得的奖励，并提供离开等操作。
- 离开游戏页面时，本局金币通过 `commitSessionCoins()` 计入永久金币。

## 当前体验边界

- 攻击在第 5 次有效交换时自动触发，玩家目前不能选择爆发时机。
- 一场战斗的主目标始终是击杀单只怪物；关卡尚无独立的棋盘目标、护送目标或阶段目标。
- 第 77 关后仍可继续递增关卡号；怪物加载会回退到最后一只已配置的怪物。详见 [06-known-gaps.md](06-known-gaps.md)。

## 目标规则：Boss 宝箱构筑

以下规则是下一步实现目标，将替换独立肉鸽模式及其商店：

1. 局外只保留英雄解锁；玩家在开局从已解锁英雄中搭配队伍。
2. 远征内不出现商店、普通关结算或招募页。普通怪死亡后暂停约 0.7 秒，下一只怪物从屏幕上方走到战斗位置。
3. 本局金币是开 Boss 宝箱的唯一消费资源。普通怪、D 方块与奖励负责产出本局金币。
4. Boss 死亡后，战斗画面进入短暂的“宝箱可开启”状态；宝箱直接显示在画面中，玩家点击并支付金币开启。
5. 宝箱随机给出局内效果或候选英雄。局内效果立即生效并在本局结束时清除。
6. 候选英雄需要玩家点击确认，再点击一名当前出战英雄进行替换；被替换英雄仅离开本局队伍，不影响局外解锁。
7. 候选英雄出现后若未在时限内点击确认，或玩家主动跳过，则将其转为该宝箱开启价格 50% 的本局金币。
8. Boss 宝箱处理完毕后，自动进入下一关；只有玩家失败才显示整局结算。
