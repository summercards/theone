## 设计支柱（从当前实现归纳）

1. 用消除为队伍制造伤害、金币、治疗、爆炸和充能。
2. 组建最多五名英雄的队伍，并用同职业/同色块形成收益。
3. 以单局连续远征贯穿所有关卡；每个 Boss 后用宝箱提供局内构筑与换人。
4. 局外只保留英雄解锁与入场队伍搭配；局内效果和英雄变更在本局结束后清除。

## 术语

- **本局金币**：当前战斗会话中获得或花费的金币；退出战斗时结算入永久金币。
- **攻击槽**：由消除和部分技能累积的待造成伤害。
- **技能充能**：每位出战英雄独立的 0–100% 充能；满后会触发技能释放。
- **有效交换**：交换后产生至少一组 3 连或以上的操作。
- **主线**：从酒馆选队后进入、按 `lastLevel` 续关的常规关卡流程。
